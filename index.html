Programme prévu pour le slot 0

Ce programme logique sélectionne les langues suivantes : Cri, Mohawk, Navajo, Inuktitut, Mi'kmaq.

slot 0:
- afficher la langue actuelle
- bouton droit = langue suivante
- bouton gauche = langue précédente
- parler la langue sur le site web
Important : Chrome/Edge exige un clic utilisateur pour Bluetooth. Une page web ne peut pas se connecter automatiquement au chargement.

Important : le bouton “Sauvegarder dans le slot 0” envoie une commande de test au hub. Pour vraiment installer un programme officiel dans le slot 0, il faut utiliser l’application LEGO SPIKE, Pybricks, ou implémenter le protocole complet de transfert de programme LEGO.
